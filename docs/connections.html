Choosing a Connection Method

reMarkableSync can access your notebooks through USB, Wi-Fi, or reMarkable Cloud. All three methods download your data without modifying the tablet or cloud.

Method Best for Main limitation
USB The most reliable and complete direct backup Requires a cable and SSH/developer access
Wi-Fi Direct backups without connecting a cable The computer and tablet must share a network
Cloud Syncing while the tablet is unavailable or elsewhere May not show older inactive files without Connect

USB

Connect directly to the tablet with a USB cable.

Advantages
  • Most reliable connection
  • Works without internet or local Wi-Fi
  • Includes built-in system templates
  • Provides the complete data currently stored on the tablet
Limitations
  • Requires the tablet and a USB cable
  • Requires SSH/developer access to be enabled

Wi-Fi

Connect directly to the tablet over its local network address.

Advantages
  • No cable required
  • Includes built-in system templates
  • Provides the complete data currently stored on the tablet
Limitations
  • Requires the tablet to be nearby and online
  • Both devices must be on the same network
  • Requires Wi-Fi SSH access

Cloud

Download notebooks from reMarkable's servers using desktop-app authentication.

Advantages
  • The tablet does not need to be nearby or online
  • Works from any internet connection
  • Uses a one-time pairing flow and securely saved device token
Limitations
  • Usually slower than a direct connection
  • Built-in system templates are not available
  • Requires internet access and reMarkable Cloud availability
  • Without Connect, inactive files may disappear from listings after 50 days

Which should I choose?

Choose USB when reliability and a complete tablet snapshot matter most. Choose Wi-Fi for the same direct access without a cable. Choose Cloud when the tablet is not nearby or you want sync to run independently of it.

You can change the method later by running reMarkableSync config again.

Cloud retention: without a Connect subscription, files inactive for more than 50 days may stop appearing in cloud listings until they are reopened on the tablet. The wizard lets you retain missing local files or move previously tracked files into a reversible Cloud Archive.

Configure reMarkableSync

Run reMarkableSync config, select a connection method, and follow the prompts. For cloud pairing instructions, see Cloud Setup.
